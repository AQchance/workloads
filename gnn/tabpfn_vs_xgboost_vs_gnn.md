## 注释

1. TabPFN 和 XGBoost 使用**相同 5-Fold 划分**、**相同 90 维扁平特征**、**2306 条查询**（时延 ≤200s），严格公平对比
2. GNN 为 4 头多任务 GATv2Conv（`train_ndv.py`，seed=42，250 epochs，1846 条查询），使用**图结构特征**（91 维节点 + 5 维边），输入空间与扁平模型不同，非严格同等对比
3. 网络 IO 的 GNN 列为 **estRows 线性回归**结果（P50=1.13x），非 GNN 模型。该维度信息量已被算子估算行数完全捕获，不需要任何 ML 模型
4. TabPFN 的 R² 在实验过程中未单独记录（in-context learning 无显式优化目标），以「—」标记
5. 所有 **Q-error 均为原始空间**（非 log 空间），定义：max(pred/true, true/pred)，越低越好

## 核心结论

| | TabPFN | XGBoost | GNN |
|------|---------|--------|------|
| P50 最优次数 | **5 / 5** | 0 / 5 | 0 / 5 |
| 需要调参 | 否 | 是（逐维度 GridSearch） | 是（多任务、LR、dropout） |
| 训练时间 | ~37s / fold | ~4s / fold | ~30min（GPU） |
| 输入 | 90 维扁平向量 | 90 维扁平向量 | 图结构（节点+边） |
| 内存尾部崩溃 | 否（P95=2.48x） | 否（P95=2.66x） | **是（P95=71.48x）** |
| 论文可用性 | NeurIPS 2023 / 2024-25 v2+ | SIGMOD 2024（Stage） | 经典方法 |
